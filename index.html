Tsurumi Stones

CONFIG

  • Double-click empty space: add node
  • Double-click node: add stone
  • Double-click stone, then click a node: set target
  • Drag stone: move it to another node
  • Drag empty node: move node
  • Double-click a node, hold, and drag to another node: link / unlink
  • Click, then Delete key: remove

SOLVE

  • Drag a stone to an empty, linked node
  • Or click a stone, then click the node
  • Ctrl+Z: undo
  • Hint: show the next best move
  • Auto-solve: the computer plays the shortest solution

BOTH

  • Load puzzle: pick one of the built-in puzzles
解

Puzzle solved
